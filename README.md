公开范围为上述14个固定文件。原始交易、持仓证据、配置、缓存、程序和凭证不公开；账户状态文档为用户特别授权的例外。

盘前行情使用最近已收盘交易日，盘后条件计划注明真实收盘日期，不能视为次日盘中报价。每条新闻保留原发布时间、采集时间、来源和覆盖缺口；渲染/发布更新时间不替代事实日期。

正式研究池按用户2026-10-08晚确认的四条件：主板60/00/003、正PE、0＜股价≤48、非ST/停牌且非黑名单；RR≥2（事件埋伏≥3）；参考买点在MA5/10附近或核验平台；当日板块≥3涨停或龙头封板代理。前三条过但无当日共振仅观察，前三条不过移出；上限5只，不凑数。开盘前尚无当日共振时允许正式池为0，仍列有效观察及全部人工种子。150只历史技术预选不代表全市场技术穷尽；报告注明未评估数。

账户、周频率、盘中承接缺确认不再否决研究池，但执行前仍须人工核验。账户缺文件按用户授权假设空仓/周0/中性研究，不写成真实成交或持仓事实；过期确认明确显示日期。三黑名单000021/000733/002185仅事件观察。

技术计算：买点取MA5/10区间、前20/60日高点为两级压力目标，历史不足明确标缺失，不编造输入；目标不因RR不足上调。20日波动率分档止损5%/8%/10%；风险≤200元，仓位上限4000/2500/2000元和可用资金共同约束，向下100股整手。建议仓位并非成交。种子旧价仅参考，现价/计划按最新可核验历史计算，破止损标⛔移出研究名单。

产业链传导依据结构化商品幅度和逐事件语义复核，禁止正文相似词直接召回个股。油价正向>3%、黄金>2%、铜/碳酸锂>3%触发相关链；地缘方向按实际事实条件区分升级/降温。名单内按实际业务直接性及当前市值排序，并非声称全行业市值前三。未复核方向写待人工确认，不把上涨链套用下跌消息。美联储仅金融传导。商品报价与股票收盘有各自日期、时区和延迟说明。

MD与配套CSV由同一数据生成；CSV第一行为合法表头，更新时间放字段，UTF-8编码。daily_review两MD别名同内容；review日志为逐日汇总，不覆盖过去交易日。08:45为发布目标，网络或来源缺失如实记录迟到/失败，无法保证时点前全部完成。

数据来自公开渠道。脚本只读与输出，不连接券商、不下单，不生成最终买入指令；内容是研究素材，需人工复核。
