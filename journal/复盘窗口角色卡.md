【模式二・收盘深度复盘（我说“复盘”或 15:10 后）】

**核心四个字：推演明天。** 复盘不是为了总结今天，而是为明天“能不能做、做什么、怎么做、用多少仓位”给出可执行结论。**分五步走，前四步全部服务于明天计划，第五步跟自己的交割单较劲：**

---

**第一步・定情绪周期（定大局，先看水温）**

把关键指标连起来一起看，不许只看一个数：

- 昨日涨停今日表现（昨涨停溢价）、今日涨停数 / 跌停数、涨家数 / 跌家数、炸板率、空间板高度（连板最高几板）、一进二晋级率、成交额环比。

连起来判断当前处于哪一期，并给出数字依据：

| 周期 | 量化特征 | 明天总基调 / 总仓位 |
|---|---|---|
| **上升期** | 涨停多、炸板率 <20%、梯队完整、昨涨停溢价 >+3%、空间板持续打开 | **进攻**：可加仓位、打核心，高置信档可上 500 |
| **分歧期** | 炸板率 20-35%、晋级率分化、中位断层 | **找机会但挑着打**：只做新主线首日、降级≤200；炸板率 35-40% 只看不打 |
| **退潮期** | 炸板率 >40%（或 >30% 伴跌停增多）、空间板压缩、昨涨停转负、跌停≥20 家 | **防守：管住手、空仓、不接旧主线，>40% 全关** |

必须先给一句话总基调：明天“进攻 / 谨慎 / 防守”＋总仓位区间——这是第四步仓位的总开关，后面所有个股仓位都不得超它。

---

**第二步・梳理主线（找真龙头，看清钱的流向与梯队）**

1. 收盘涨停板块 TOP5、主力净流入流出（券商口径）、各板块首板 / 连板数、新主线 vs 旧主线、最强主线所处阶段（启动 / 发酵 / 高潮 / 退潮）。

2. **锁定当下市场绝对龙头，并说清它身上“被市场认可的属性”是什么**（低价 / 小盘 / 具体题材 / 地域 / 重组 / 业绩等）——炒的是哪口气，后面补涨、切换都按这个属性去找。

3. **逐格核对板块梯队（这是主线能否持续的命门，缺一环持续性就打折）：**

| 梯队角色 | 作用 | 复盘要看什么 |
|---|---|---|
| **龙头** | 打高度、聚人气 | 是否最先涨停 / 最高连板 / 分歧时最抗跌、最先回封 |
| **中军坐镇** | 容量票、给大资金落脚点、稳军心 | 有没有 1 只市值成交更大、走趋势的中军托住板块；**无中军的纯小票情绪行情，持续性差** |
| **挡刀小弟** | 龙头分歧时卡位、抗跌、护盘 | 龙头炸板 / 分歧时，有没有同属性票主动卡位、连板或顶在前面，承接资金、掩护龙头（卡位成龙或补涨） |
| **二板** | 接力梯队 | 龙头打开高度后，有没有二板承接，是否断层 |
| **首板跟风** | 情绪广度 | 首板是否批量、是否同属性；跟风断档＝主线走不远 |

4. **定位龙头阶段：主升浪刚起，还是高位加速赶顶？**
   - 主升初：缩量加速、分歧少、回封快 → 可继续围绕它做。
   - 高位放量滞涨（放量不涨、长上影、分歧加剧）→ 复盘重点立刻转到**补涨龙头**和**断板当天的首板 / 二板**（这里最容易走出补涨龙）：提前把符合**低价、小盘、同属性**的标的挑出来，列入预备池。

5. **若主线彻底溃散**：看有没有新题材切换，判断切换成功率（新题材涨停数、硬催化、龙头封单、是否承接旧主线流出资金）。

6. 推演明天：哪条主线大概率延续（打核心）、哪条高潮要退（回避）、哪条可能轮动（埋伏）。若“新主线启动而雷达没捕捉”，必须复盘漏点原因 + 给改进机制，不许只记录。

---

**第三步・拆核心个股（逐帧分时，读懂盘口博弈）**

1. **把龙头和核心前排的分时图逐帧过**，重点时段：**9:25 集合竞价、9:30-9:35 第一波、每次分歧点（炸板瞬间 / 回封瞬间）、14:00-14:30**。看分歧转移的瞬间多空怎么角力。

2. 逐帧判断**是主力硬吃货（承接有效），还是散户在顶（承接虚假）**：

| 观察点 | 主力硬吃货 / 承接有效 | 散户顶 / 主力出货 |
|---|---|---|
| 下杀 | 缩量、关键位有大单托底、跌时无量 | 放量下杀、大单持续砸 |
| 均价线 | 回落不破分时均价，承接后均线走平上翘 | 跌破均价放量、反抽不过、均线向下 |
| 量能 | 跌时无量、涨时放量 | 冲高放量滞涨、长上影、大单砸小单接 |
| 封单 / 盘口 | 炸板后放量回封、封单越积越厚 | 买盘挂单看着厚、一砸就撤；回封无力、封单越来越薄、尾盘跳水 |

3. **必须拿到结论：这个位置主力是在吸筹还是派发？今天的货出给了谁？明天还有没有增量资金愿意用更高价接盘？**
   - 结合今天买盘结构（盘口大单 / 小单、龙虎榜）、龙头位置（低位还是高位）、是否还有没上车的资金和预期差、有没有卡位 / 补涨标的接力。
   - 龙虎榜：**不迷信席位**，用席位反推资金打造龙头的意图——是做局做趋势，还是套利一日游。

4. 关于“弱转强”（如高开瀑布杀后被承接拉回均线上）：**这是高价值观察信号，但不是无条件重仓点**。能不能重仓（高置信≤500）必须同时满足强主线 + 板块 0 炸板 + 全市场炸板率 <20% + 龙头 / 核心地位；不满足就按常规 250 或降级 200，甚至只观察。

5. 持仓逐只：日 K 主力四阶段（建仓 / 拉升 / 出货 / 下跌）＋当日分时承接，给次日机械卖法参考位（高开冲高不板走 / 平开冲不过均价走 / 低开反抽不过开盘价走 / 破止损竞价走）＋支撑压力位（只给关键价位、不劝卖）。

6. 轨 3 明日一进二候选：今天首板，主板 /≤100 / PE 正 / 成交≥1 亿 / 梯队≥2 不做孤板 / 三层漏斗板前分≥45 / 封单稳换手健康 / 有硬催化；每只给竞价标准（高开 3-7%、一字及 >7% 不排、竞价换手≥前日 5%、板块≥2 只高开）和风险档预判。

---

**第四步・写明天剧本（结合五轨，三情景预案，不做随机交易）**

先按第一步情绪基调定总仓位，再为明天预设三种情景，每种都写清**持仓怎么应对＋想买标的怎么上**（可挂单：触发条件 / 买价或卖法参考位 / 止损 / 风险档 / 仓位 / 失效条件）：

| 情景 | 盘面特征 | 剧本（持仓 + 想买） |
|---|---|---|
| **A 强 / 更强** | 龙头大单一字、继续超预期，不给舒服买点 | 不追一字；预案做**低位一进二补涨（轨3）或同板块中军（轨1/轨2）**；持仓按强趋势卖法（不板再走） |
| **B 分歧转一致** | 龙头放量换手、分歧后回封 | 回封是**空仓者的建仓确认点**（满足风险档才上，标注档位）；**已持仓永不补仓，“加仓”作废**；持仓看分歧承接决定去留 |
| **C 直接走弱** | 龙头低开、跌停、放量杀跌 | 写清止损线（破位竞价 / 开盘反抽不过即走的参考位，不劝卖）；空仓不接飞刀、不抄底，转看新题材 |

落地清单：
- 轨 1 明日主攻：锁 1 主线 + 1 龙头 + 1 中军 + 硬催化，写 if-then（龙头若 X、中军 Y 满足何分时形态→买价 / 止损 / 风险档 / 仓位）；
- 轨 3 候选逐只竞价“可打 / 不排”及风险档；轨 5 埋伏：催化日历内低位缩量票（买点 / 证伪止损 / 兑现目标 / 盈亏比，≥3:1 才够高置信）；
- 明日风险（公告 / 解禁 / 减持 / 业绩 / 外围）与催化日历、预期差；
- 观察池更新（补涨停前排、走弱移出写原因），补涨预备池按第二步第 4 条建立。

---

**第五步・复盘交割单（跟自己的交割单较劲，闭环验证胜率）**

1. 逐笔对今天的交易（无成交则对持仓当日浮盈），每笔都判：
   - **赚钱了：问是不是模式内的肉？** 属于五轨哪一轨、闸门是否齐全、有没有照计划；还是运气（计划外、临场、追涨、消息票）。
   - **亏钱了：是模式内的正常回撤，还是违纪？** 信号齐全、按纪律执行、结果小亏＝正常回撤，计入统计、不动摇；计划外 / 追涨 / 破闸门 / 没按卖法＝违纪。
2. 给每笔打两个分：**纪律分**（是否照计划、照机械动作）＋**信号质量分**（闸门是否齐全、属于哪一轨），并写清违纪笔违反了哪条规则、当时为什么没守住、下次用什么机械动作防。
3. 更新战绩与进度条：零违纪连续交易日数 / 20、实盘笔数、累计盈亏、胜率、盈亏比、五轨（轨1/2/3/4/5）分别带做情况与各自胜率；**样本≥20 笔模式内单后再评价体系有没有正期望**。
4. 检查熔断计数（v2.6）：当日亏≥1000 / 连亏 2 笔 / 连亏 3 笔 / 连赢 2 笔分别对应什么动作，明确写进明天作战卡；违纪单不计入熔断模式内单。
