## 数据口径

盘前使用最近已收盘交易日行情，绝不冒充当日盘中现价。手动盘后生成的次日条件计划会标注实际模式和日期。行情新浪/腾讯直连；分类申万/新浪及有日期的本地资料；政策与新闻列原始官网或指定媒体链接。禁用东方财富和tushare。

事实字段缺源保持NA。技术计划以核验过的未复权日线计算：低吸/尾盘参考区间为MA5与MA10之间，保守参考价取上沿；尾盘区间不是已知分时均价，必须14:30核验。第一/第二目标为最近收盘日前20/最多60交易日最高价，不为凑盈亏比抬高目标，目标低于参考价也显示数值。每行附计算依据。历史不足须写原因，不能造数。

止损按20日收益标准差：≤2%止损5%，2%—4%止损8%，>4%止损10%，止损价向上取分。RR=(第一目标−参考价)/(参考价−止损)。建议股数向下100股整数手，同时受理论风险200元和4000/2500/2000元仓位上限限制；不足一手可为0。跳空、滑点和费用可能使实际损失超过理论风险。

正式池上限5，不足3明确写今日仅X只达标，并列最接近候选与未过闸原因。主辅RR≥2，埋伏≥3，股性、黑名单、人工三周期、阶段/频率/单票名额等闸不放宽。技术价位有数值不代表允许下单。预期差定性与真实持仓证据不得机器补填。

突发扫描平日24小时，长假后回溯假期；各源有抓取上限，覆盖不足/失败/时间待核验必须可见。消息重要性为检索优先级，不代表受益概率；传导为条件推断。无合格标的指本次已核验覆盖内，不声称全市场不存在。日历财报按时间/ID排序最多占80%，省略项保留本地审计。

复盘只统计人工确认的实际记录。没有盘中记录写NA，不用收盘倒推信号、不把缺记录写无触发。情绪周期由人工确认，机器仅列客观温度与素材。

## 发布核验

本仓库仅公开以上10个文件。发布后逐个核对raw HTTP200/201和内容SHA256；失败最多重试2次，不影响本地输出。远端文件的时间可能不同，应逐份核对更新时间、模式与行情日期；网络异常可能迟于目标发布时间。

raw地址前缀：`https://raw.githubusercontent.com/amvzzc-arch/a-share-data/main/`，后接表中固定文件名。

数据来自公开渠道，脚本只读与输出，不连接券商、不下单。所有内容仅为投研素材，需人工复核，不构成买卖建议。
