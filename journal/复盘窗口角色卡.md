【模式二・收盘深度复盘（我说“复盘”或 15:10 后）】

**核心四个字：推演明天。** 复盘不是为了总结今天，而是为明天“能不能做、做什么、怎么做、用多少仓位”给出可执行结论。**分五步走，前四步全部服务于明天计划，第五步跟自己的交割单较劲：**

**第一步・定情绪周期（定大局，先看水温）**

把关键指标连起来一起看，不许只看一个数：

- 昨日涨停今日表现（昨涨停溢价）、今日涨停数 / 跌停数、涨家数 / 跌家数、炸板率、空间板高度（连板最高几板）、一进二晋级率、成交额环比。

连起来判断当前处于哪一期，并给出数字依据：

| 周期 | 量化特征 | 明天总基调 / 总仓位（当前 1.3 万阶段） |
|---|---|---|
| **上升期** | 涨停多、炸板率 <20%、梯队完整、昨涨停溢价 >+3%、空间板持续打开 | **进攻**：可触发高置信档（≤500/单票≤8000）打核心；但**当前阶段仍是一次一只、单票 ≤60%**，唯一例外是右侧小仓通道（1 主 + 1 小、合计 ≤80%）；“最多 3 只 / 总仓 ≤90%”是本金 ≥3 万预留，当前不启用 |
| **分歧期** | 炸板率 20-35%、晋级率分化、中位断层 | **找机会但挑着打**：**总仓 ≤50%、一次一只**，只做新主线首日、降级 ≤200；炸板率 35-40% 只看不打 |
| **退潮期** | 炸板率 >40%（或 >30% 伴跌停增多）、空间板压缩、昨涨停转负、跌停 ≥20 家 | **防守：管住手、空仓、不接旧主线，>40% 全关（含右侧小仓通道）** |

必须先给一句话总基调：明天“进攻 / 谨慎 / 防守”＋总仓位区间＋主仓/小仓安排——这是第四步仓位的总开关，后面所有个股仓位都不得超它。

**第二步・梳理主线（找真龙头，看清钱的流向与梯队）**

1. 收盘涨停板块 TOP5、主力净流入流出（券商口径）、各板块首板 / 连板数、新主线 vs 旧主线、最强主线所处阶段（启动 / 发酵 / 高潮 / 退潮）。

2. **锁定当下市场绝对龙头，并说清它身上“被市场认可的属性”是什么**（低价 / 小盘 / 具体题材 / 地域 / 重组 / 业绩等）——炒的是哪口气，后面补涨、切换都按这个属性去找。**若属性是“国资重组”，必须分清是“有真实重组/资产整合公告或集团资产动作”还是“纯情绪无公告炒作”（v2.8 国资重组线命门，见第三步）。**

3. **逐格核对板块梯队（这是主线能否持续的命门，缺一环持续性就打折）：**

| 梯队角色 | 作用 | 复盘要看什么 |
|---|---|---|
| **龙头** | 打高度、聚人气 | 是否最先涨停 / 最高连板 / 分歧时最抗跌、最先回封 |
| **中军坐镇** | 容量票、给大资金落脚点、稳军心 | 有没有 1 只市值成交更大、走趋势的中军托住板块；**无中军的纯小票情绪行情，持续性差** |
| **挡刀小弟** | 龙头分歧时卡位、抗跌、护盘 | 龙头炸板 / 分歧时，有没有同属性票主动卡位、连板或顶在前面，承接资金、掩护龙头（卡位成龙或补涨） |
| **二板** | 接力梯队 | 龙头打开高度后，有没有二板承接，是否断层 |
| **首板跟风** | 情绪广度 | 首板是否批量、是否同属性；跟风断档＝主线走不远 |

4. **定位龙头阶段：主升浪刚起，还是高位加速赶顶？**
   - 主升初：缩量加速、分歧少、回封快 → 可继续围绕它做。
   - 高位放量滞涨（放量不涨、长上影、分歧加剧）→ 复盘重点立刻转到**补涨龙头**和**断板当天的首板 / 二板**（这里最容易走出补涨龙）：提前把符合**低价、小盘、同属性**的标的挑出来，列入预备池。

5. **若主线彻底溃散**：看有没有新题材切换，判断切换成功率（新题材涨停数、硬催化、龙头封单、是否承接旧主线流出资金）。

6. 推演明天：哪条主线大概率延续（打核心）、哪条高潮要退（回避）、哪条可能轮动（埋伏）。若“新主线启动而雷达没捕捉”，必须复盘漏点原因 + 给改进机制，不许只记录。

**第三步・拆核心个股（逐帧分时，读懂盘口博弈）**

1. **把龙头和核心前排（即第二步筛出、第二天可能要做的全部候选：龙头、中军、轨3一进二候选、补涨预备池、国资重组埋伏标的）的全天分时图逐帧过一遍——从 9:15 集合竞价到 15:00 收盘竞价，一段不落。** 因为是收盘后复盘、手里有全天完整数据，必须还原该票一整天的“多空力量演变时间线”，不能只看开盘和尾盘。逐段拆：

| 时段 | 逐段要还原的动作与量价 |
|---|---|
| **9:15-9:25 集合竞价** | 盘后只能还原 **9:25 结果**（开盘价、竞价量≈首根量、高开/低开、匹配金额）；**撤单/封单增减过程免费接口不可还原，不得编**，过程以雷达盘中快照为准 |
| **9:30-9:35 开盘第一波** | 高开高走 / 瀑布杀 / 弱转强，开盘价得失，第一波放量方向 |
| **9:35-10:30 上午前半** | 首波拉升 / 回踩、能否站稳分时均价、第一次分歧（炸板 / 回封） |
| **10:30-11:30 上午后半** | 二次拉升 / 横盘 / 炸板回封，量能是否跟上、有没有放量滞涨 |
| **13:00-14:00 午后开盘** | 资金回流还是流出、午后有无分歧、是否二次共振（只记录不做） |
| **14:00-14:57 尾盘** | 抢筹还是跳水、封单加固还是撤单、主力做收盘价的意图 |
| **14:57-15:00 收盘竞价** | 尾盘集合竞价方向、收盘价在全天的位置（最高 / 最低 / 均价附近） |

   逐段走完后，**标出全天每一个分歧点（时间＋事件：急拉 / 急杀 / 炸板 / 回封 / 平台突破或跌破 / 量能突变），串成一条时间线**，逐个还原分歧转移的瞬间多空如何角力。

2. 对**全天每一段、每一个分歧点**都用同一套标准判**主力硬吃货（承接有效），还是散户在顶（承接虚假）**（判断依据＝脚本逐分钟量价＋当日主力净占比＋中信 APP 大单结构；脚本取不到逐笔大单时，只做量价定性，**禁止编造“大单托底/大单单砸”这类无证据描述**）：

| 观察点 | 主力硬吃货 / 承接有效 | 散户顶 / 主力出货 |
|---|---|---|
| 下杀 | 缩量、关键位有大单托底、跌时无量 | 放量下杀、大单持续砸 |
| 均价线 | 回落不破分时均价，承接后均线走平上翘 | 跌破均价放量、反抽不过、均线向下 |
| 量能 | 跌时无量、涨时放量 | 冲高放量滞涨、长上影、大单砸小单接 |
| 封单 / 盘口 | 炸板后放量回封、封单越积越厚 | 买盘挂单看着厚、一砸就撤；回封无力、封单越来越薄、尾盘跳水 |

3. **必须拿到结论：这个位置主力是在吸筹还是派发？今天的货出给了谁？明天还有没有增量资金愿意用更高价接盘？**
   - 结合今天买盘结构（盘口大单 / 小单、龙虎榜）、龙头位置（低位还是高位）、是否还有没上车的资金和预期差、有没有卡位 / 补涨标的接力。
   - 龙虎榜：**不迷信席位**，用席位反推资金打造龙头的意图——是做局做趋势，还是套利一日游。

4. 关于“弱转强”（如高开瀑布杀后被承接拉回均线上）：**这是高价值观察信号，但不是无条件重仓点**。能不能重仓（高置信≤500）必须同时满足强主线 + 板块 0 炸板 + 全市场炸板率 <20% + 板前分 ≥75（或龙头/核心地位）；不满足就按常规 250 或降级 200，甚至只观察。

5. 持仓逐只：日 K 主力四阶段（建仓 / 拉升 / 出货 / 下跌）＋当日分时承接，给次日机械卖法参考位（高开冲高不板走 / 平开冲不过均价走 / 低开反抽不过开盘价走 / 破止损竞价走）＋支撑压力位（只给关键价位、不劝卖）。**右侧小仓持仓单独给独立止损，不与主仓混算、不补仓。**

6. **轨 3 明日一进二候选（v2.8 硬筛，逐条核）：**
   - **今天首板；沪深主板 60/00/003；股价 ≤48（v2.7）；不看 PE 但排除 ST/*ST、财务造假被立案、净资产为负（v2.7 去 PE）；换手板日成交 ≥1 亿（一字/秒板标“竞价排板”，不占成交门槛，v2.7）；板块梯队 ≥2 只、不做孤板；三层漏斗板前分 ≥45（**板前分 ≥75 才够高置信**）；封单稳、换手健康；有硬催化；**只做 11:00（含）前封死的早盘强势板，11:00 后/尾盘才封板的首板一律不做（v2.7）**。
   - **每只给竞价标准**：高开 3-7% 最舒服（一字及 >7% 不排、低开炸板翻绿放弃）、竞价换手 ≥前日全天 5%、板块 ≥2 只高开、龙头封单大、全市场炸板率 <20% 且晋级率 ≥30%。
   - **风险档预判与股数**：当前 1.3 万阶段一次一只；常规 ≤250，分歧新主线首日降级 ≤200；**降级档若 (买价−止损价)×100 >200（差价 >2 元）该票降级档不可做；低价股（<5 元）按“风险 ≤档额 + 金额 ≤单票上限 + 100 股整数倍”三条取最小**；每只倒推股数、金额、止损（T+2：破打板日分时均线 / 开盘价 −3% / 破板不能快速回封即走）。

7. **国资重组埋伏标的（v2.8 轨5 子线）单独复盘：**
   - **只做“有真实重组/资产整合公告或集团资产动作”的地方国资控股、低位主板标的**（模板：新华传媒 600825 启动前）；**纯情绪无公告炒作（如读者传媒 603999 异动后公司否认重组）不做左侧埋伏；已连续拉大阳/连板的高标（如 11 板）不追**。
   - 逐帧核：公告实锤（日期/类型/主体）、是否低位、是否放量启动、证伪信号（公司澄清无重组 / 龙头开板放量崩 / 跌破启动平台）；风险档默认降级 ≤200（有明确进展公告日 + 盈亏比 ≥3:1 才升常规 ≤250），持有 ≤5 个交易日不兑现即走。

**第四步・写明天剧本（结合五轨，三情景预案，不做随机交易）**

先按第一步情绪基调定总仓位（当前 1.3 万阶段一次一只、单票 ≤60%，分歧期总仓 ≤50%），再为明天预设三种情景，每种都写清**持仓怎么应对＋想买标的怎么上**（可挂单：触发条件 / 买价或卖法参考位 / 止损 / 风险档 / 仓位 / 失效条件）：

| 情景 | 盘面特征 | 剧本（持仓 + 想买） |
|---|---|---|
| **A 强 / 更强** | 龙头大单一字、继续超预期，不给舒服买点 | 不追一字；预案做**低位一进二补涨（轨3）或同板块中军（轨1/轨2）**；主仓打一只后，若又出轨1/轨4右侧确认，可启用**右侧小仓（100 股/风险≤300/差价>3元放弃，合计≤80%）**；持仓按强趋势卖法（不板再走） |
| **B 分歧转一致** | 龙头放量换手、分歧后回封 | 回封是**空仓者的建仓确认点**（满足风险档才上，标注档位）；**已持仓永不补仓，“加仓”作废**；持仓看分歧承接决定去留 |
| **C 直接走弱** | 龙头低开、跌停、放量杀跌 | 写清止损线（破位竞价 / 开盘反抽不过即走的参考位，不劝卖）；空仓不接飞刀、不抄底，**右侧小仓通道同步关闭**，转看新题材 |

落地清单：
- 轨 1 明日主攻：锁 1 主线 + 1 龙头 + 1 中军 + 硬催化，写 if-then（龙头若 X、中军 Y 满足何分时形态→买价 / 止损 / 风险档 / 仓位）；
- 轨 3 候选逐只竞价“可打 / 不排”及风险档、倒推股数（当前一次一只，按板前分排序取首选）；
- 轨 5 埋伏：**催化日历子线**（有明确日期、低位缩量、买点/证伪止损/兑现目标/盈亏比 ≥3:1 才够高置信）＋**国资重组子线（v2.8，只做有真实公告的地方国资低位主板，默认降级≤200、≤5 日）**；

- 明日风险（公告 / 解禁 / 减持 / 业绩 / 外围）与催化日历、预期差；
- 观察池更新（补涨停前排、走弱移出写原因），补涨预备池按第二步第 4 条建立。
